# 📝 TextCraft Studio

**Linguistic Deconstructor & Advanced Writing Masterclass**

TextCraft হলো একটি পূর্ণাঙ্গ linguistic analysis tool যা যেকোনো আর্টিকেল, রচনা, পিডিএফ ডকুমেন্ট কিংবা ওয়েব URL দিলে তা স্বয়ংক্রিয়ভাবে ৪টি স্তরে ব্যবচ্ছেদ করে এবং উন্নত মানের লেখা শেখার স্টেপ-বাই-স্টেপ রোডম্যাপ প্রদান করে।

## 🌟 Features

### 1. 📊 Basic Info & 5W1H Information Matrix
- মৌলিক তথ্য ও কাঠামো বিশ্লেষণ
- দ্বিভাষিক (বাংলা + ইংরেজি) উপস্থাপনা
- Core Thesis & Focus Analysis

### 2. 📚 GRE High-Frequency Vocabulary Matrix
- উন্নত GRE/Academic শব্দে রূপান্তর
- Synonym nuances, antonyms, etymology
- Flashcard Mode & CSV Download

### 3. 🔬 Clause & Grammar X-Ray
- প্রতিটি বাক্যের syntactic formula
- Beginner vs Editorial তুলনা
- বাংলায় ব্যাকরণগত বিশ্লেষণ

### 4. 🎓 Writing Masterclass Blueprint
- 5-step writing transformation guide
- Plug-and-Play clause templates
- Interactive editorial checklist

### 5. 🔄 Sentence Transformer Lab
- 4-level sentence transformation
- Real-time practice with any text

## 🚀 Setup & Installation

### Prerequisites
- Python 3.8+
- Google Gemini API Key (Free at https://aistudio.google.com/apikey)

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/textcraft-studio.git
cd textcraft-studio

# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
